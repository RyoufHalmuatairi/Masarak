# تحليل السيرة — خادم التجربة المحلية

1. ضع المفتاح في `server/.env` بعد `GROQ_API_KEY=`. لا تضعه في `.env.example` أو في تطبيق الجوال.
2. من جذر المشروع شغّل `npm.cmd run cv-server` في ترمينال مستقل، واترك Expo يعمل في ترميناله.
3. الآيفون والكمبيوتر على نفس شبكة الواي فاي. إذا ظهر طلب Windows Firewall فاسمح للشبكة الخاصة فقط.
4. التطبيق يستنتج عنوان الكمبيوتر من اتصال Expo في التطوير. إذا كنت تستخدم tunnel، عيّن عنوان الكمبيوتر المحلي في `EXPO_PUBLIC_CV_API_URL` ثم أعد تشغيل Expo.

الملف يُقرأ في ذاكرة الخادم ويُرسل نصه إلى Groq بعد موافقة المستخدم. لا يحفظ الخادم السيرة أو يسجل المحتوى. النسخة الحالية تدعم PDF النصي وDOCX؛ لا يوجد OCR للصور. حدود التجربة: 10 ميجابايت، 15 صفحة PDF، 24000 حرف. يتم رفض النص الطويل دون قطع صامت.

المعلومات المستخرجة اقتراحات تحتاج مراجعة، والاستشهاد النصي يثبت وجود النص فقط ولا يثبت صحة الشهادة أو إتقان المهارة. المطابقة تستخدم أسماء SSF ومرادفات عربية وإنجليزية. المهارة ترفع النسبة عندما تطابق متطلبًا أساسيًا للمسار فقط؛ التفاصيل والمصادر في docs/DATASET_AND_SCORING_AR.md. الشهادات والخبرات تحفظ للمراجعة ولا تدخل حساب التغطية الحالي.

هذا خادم تطوير محلي بدون حسابات مستخدمين، وليس جاهزًا للنشر العام. قبل نشره يلزم توثيق المستخدمين وHTTPS وحدود مناسبة وسياسة خصوصية وحذف بيانات. استخدم سيرة تجريبية أولًا. لا تفعّل فوترة Groq أثناء التجربة المجانية.

المصادر: https://console.groq.com/docs/structured-outputs وhttps://console.groq.com/docs/your-data

قوائم المهارات الصريحة المفصولة بفواصل (مثل Programming Languages: Java, Python, C++) تُراجع محليًا لاستعادة الأسماء التي أغفلها النموذج، دون طلب إضافي أو تخمين ربطها بالقاموس. يدعم الفحص تسميات عربية وإنجليزية ويحافظ على فصل أعمدة PDF؛ يبقى النص الوصفي والقوائم غير الواضحة بحاجة إلى مراجعة المستخدم.
