# الحسابات في مسارك

تم تفعيل إنشاء الحساب والدخول واستعادة كلمة المرور وتأكيد البريد وحفظ الجلسة وتسجيل الخروج باستخدام Supabase Auth.

## الإعداد

ملف `.env.local` في جذر التطبيق يحتوي Project URL وPublishable key فقط:

```env
EXPO_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

لا تضعي secret أو service_role أو كلمة مرور قاعدة البيانات هنا. مفتاح Groq يبقى في server/.env. أعيدي تشغيل Expo بعد تغيير إعدادات البيئة.

## تجربة الحساب

1. افتحي التطبيق واختاري تسجيل جديد.
2. استخدمي حاليًا البريد نفسه المسجل في حساب Supabase، وكلمة مرور جديدة لمسارك من 8 أحرف على الأقل.
3. افتحي رابط تأكيد البريد على الجهاز نفسه الذي يستخدم التطبيق.
4. اختبري الدخول والخروج واستعادة كلمة المرور. استعادة الجلسة تتحقق من الحساب عبر الإنترنت.

خدمة بريد Supabase الافتراضية ترسل إلى أعضاء فريق المشروع فقط، بحد رسالتين في الساعة. إطلاق التسجيل للجميع يحتاج SMTP مخصصًا؛ نختار خدمة مجانية عند الحاجة. تأكيد البريد يبقى مفعّلًا. قوالب HTML الموجودة في docs مسودات لاحقة وليست مفعلة.

## روابط التأكيد

Site URL الحالي: `http://localhost:8081/auth-callback`.

الروابط المسموحة الحالية:

- `exp://192.168.1.13:8081/--/auth-callback`
- `http://localhost:8081/auth-callback`
- `http://192.168.1.13:8081/auth-callback`
- `masarak://auth-callback`

إذا تغير عنوان الكمبيوتر على الشبكة أو منفذ Expo، حدّثي الروابط في Supabase. افتحي Expo Go قبل رابط التأكيد عند التجربة على الآيفون.

## البيانات

لكل حساب سيرة ومهارات وخطة تعلم مستقلة محفوظة محليًا على الجهاز. بيانات الضيف السابقة تبقى محفوظة في وضع الضيف. تسجيل الخروج لا يمسح ملفات الحساب. لم تتم إضافة مزامنة السيرة بين الأجهزة أو رفعها إلى Supabase.

جلسة الدخول محفوظة في SecureStore على الهاتف. كلمة المرور لا يحفظها التطبيق. مفتاح البيئة المحلي مستبعد من Git.

## التحقق

اختبارات الحسابات والملف: `node --test tests/profile-integration.test.cjs tests/auth-storage.test.cjs`.

فحص الاتصال بالإعدادات دون إنشاء حساب أو إرسال بريد: `node scripts/check-auth.mjs`.

المراجع: https://supabase.com/docs/guides/auth/quickstarts/react-native و https://supabase.com/docs/guides/auth/auth-smtp
